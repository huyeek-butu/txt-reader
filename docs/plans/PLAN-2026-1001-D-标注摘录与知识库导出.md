## 1. 目标

把"读到的东西"沉淀成结构化摘录，直接对接既有 AI 知识库。

## 2. 解决的问题

| 问题 | 说明 |
|---|---|
| 阅读器与知识链路断开 | 与 Obsidian 库（`D:\MyAIBrain\Huyee`）、LLM Wiki **无任何导出通道**，见到好句子只能外部截图/复制 |
| 进度只记位置不记内容 | 现有进度机制只保存"读到哪一行"，无法回溯"读到了什么重点" |

## 3. 实现要点

1. **选中即摘录**：选中正文文字 → 浮动工具条（高亮 / 摘录），自动记录 文件名 + 行号 + 时间戳。
2. **存储**：摘录存 `localStorage`，**沿用现有 per-file 内容指纹 key 机制**避免串档（与进度 key 分离命名空间）。
3. **导出格式**：Markdown，含 `> 引用` 块 + `[[文件名]]` 反链格式，便于直接摄入 wiki；支持复制到剪贴板，FSA 可用时直写 vault 目录（复用 PLAN-A 存盘模块）。
4. **面板**：侧栏新增「摘录」面板，按文件归组、点击跳回原文位置。
5. **高亮渲染**：必须接入现有 `visualRows` 分页管线，**不破坏分页与搜索高亮**；与搜索高亮做层叠并明确优先级（建议：搜索高亮优先，摘录高亮作底色）。
6. **数据模型**：`{ fileId, text, lineIndex, start, end, note, createdAt }` —— 以 `fileId`（内容指纹）为外键，随文件移动不丢失匹配依据。

## 4. 覆盖场景

- 阅读中选中句子 → 高亮 → 侧栏可见
- 同一文件多处摘录 → 按行号排序、点击跳转
- 多文件摘录 → 按文件分组导出
- 导出 Markdown → 粘贴进 Obsidian 得到带反链的笔记
- 重复导入同一文件（同指纹）→ 摘录正确关联

## 5. 边界情况

| 情况 | 处理 |
|---|---|
| 选中跨视觉行/跨页 | 以逻辑句为最小摘录单元，跨行自动合并 |
| 排版开启（按句分段）下选中 | 摘录位置以**原文偏移**存储，不依赖排版后行号，切开关后仍能定位 |
| 同内容不同文件 | 指纹含文件名，不误关联 |
| 摘录文本被后续排版规则改变 | 存储时同时保存原文快照，展示以原文为准 |
| localStorage 超限 | 达到阈值时提示并支持导出后清理 |
| 高亮与搜索高亮重叠 | 层叠显示，搜索高亮置顶，颜色区分 |
| 文件被删除后 | 摘录保留在面板并标「文件已移除」，可导出但不可跳转 |
