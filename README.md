# TXT 阅读器

一款**浏览器端、单文件**的 TXT 阅读工具，专为中文小说、日志、剧本等长文本设计。支持 GBK / Big5 / UTF-8 自动识别，按真实显示行分页，提供通配符搜索、按句分段排版、可拖动换行标尺、纯净阅读模式、护眼主题与快捷键操作，让阅读回归沉浸。

## 📌 项目简介

一款浏览器端的 TXT 阅读工具，专为中文小说、日志、剧本等长文本设计。支持 GBK / Big5 / UTF-8 自动识别，按真实显示行分页，提供通配符搜索、按句分段排版、可拖动换行标尺、纯净阅读模式、护眼主题与快捷键操作，让阅读回归沉浸。

## ✨ 主要功能

- **自动编码识别**：智能检测 GBK / Big5 / UTF-8，也可手动切换。
- **真实显示行分页**：按实际折行后的视觉行计算页码，翻页精准。
- **通配符搜索定位**：`*` 匹配任意长度字符、`?` 匹配单字符，文件搜索与正文搜索均支持；循环跳转、正文内联高亮、显示第 X/N 个匹配。
- **简单排版 · 按句分段**：主窗口正文与「✒ 简单排版」弹窗共用同一排版引擎（Layout 模块）——每句一段、段间空行、连续短对话合并不空行；逗号等非句末标点后的换行自动合并回同一句；破折号 `——` / 省略号 `……` 连排作为强制段落分隔。
- **连续标点组合处理**：
  - `！！`、`？！`、`!?`、`。。。` 等连排/混排标点视为**一个**句末边界——不拆句、不折叠、不转换，原样保留（保留作者语气风格）；
  - 句末标点串后的收尾引号/括号（`！”`、`。”`、`……”`、`！”）`）归入**前一句**，不会单独成段，也不会被粘到下一句开头；
  - 句首的前引号/前括号（`“`、`《`、`（`）归入该句；
  - 句边界判定（换行是否保留、是否断句）统一按「句末标点串 + 可选收尾符号」识别，`“你好！”\n他走了。` 这类换行不会丢；
  - 长标点串作分隔线时按规格剔除，但「句内省略号 + 收尾符号」（如 `……”`）会连同符号并入前一段，不丢字符。
- **换行边界标尺**：主窗口顶端 Word 式水平标尺，拖动设定换行列边界（拖动实时预览、松开才重排），双击恢复自动宽度，设置持久保存。
- **进度自动保存**：多文件独立记忆阅读位置，按内容指纹（FNV-1a）防串档，一键恢复/清除。
- **纯净阅读模式**：一键隐藏 UI，自定义字号、字体、宽度与背景色。
- **护眼主题**：明亮暖纸感 / 暗色非纯黑柔对比 / 跟随系统，一键切换。
- **自动翻页**：可设定 15–90 秒/页，空格启停。
- **字号档位**：14 / 16 / 18 / 20 / 24（默认）/ 28 / 32 / 36px。

## 🚀 基本操作

1. 点击顶栏「**打开文件**」或「**打开文件夹**」载入 TXT 文件
2. 在左侧「文件列表」切换文件；「搜索定位」与文件搜索均支持 `*` / `?` 通配符，输入后回车或点搜索按钮跳转
3. 在顶栏可调整编码、换行、字号（14–36px）、主题；点「✒ 正文排版」切换正文按句分段排版
4. 「✒ 简单排版」弹窗：粘贴大段连续文字，实时按句分段，一键复制结果
5. 拖动正文顶端**标尺**设定换行边界（松开生效），双击恢复自动
6. 点击「📖 纯净阅读」进入沉浸模式，可调整字号、字体、页面宽度与背景色，按 R 或 Esc 退出
7. 阅读进度会**自动保存**；需要时点击翻页栏「**↺ 恢复进度**」回到上次阅读位置

> **提示**：编码/字号下拉框聚焦时，PageUp / PageDown 不会触发翻页，避免误操作。

## 🔧 技术说明

- 单个 HTML 文件，内联 CSS + JS，零外部依赖
- 使用浏览器 `FileReader API` 读取本地文件，不上传服务器
- 使用浏览器 `localStorage` 保存阅读进度与设置
- 进度 key 采用内容指纹（FNV-1a 前 4KB + 字节长度），同尺寸不同文件不串档；每文件独立保存队列，切换即落盘
- 排版引擎封装为 `Layout` 模块（断句清洗 → 按句分段 → 短对话合并 → 长标点强制分段），主窗口正文与排版弹窗共用同一实现
- 大文件排版优化：采样估算真实显示行，提速约 100× 以上
- 换行标尺基于 canvas 绘制（DPR 适配），拖动过程零重排、松开才重排，大文件拖动不卡顿
- 兼容现代浏览器（Chrome / Edge / Firefox / Safari）
