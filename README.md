## 📌 项目简介

一款浏览器端的 TXT 阅读工具，专为中文小说、日志、剧本等长文本设计。支持 GBK / Big5 / UTF-8 自动识别，按真实显示行分页，提供关键词搜索、纯净阅读模式、护眼主题与快捷键操作，让阅读回归沉浸。

## ✨ 主要功能

- **自动编码识别**：智能检测 GBK / Big5 / UTF-8，也可手动切换。
- **真实显示行分页**：按实际折行后的视觉行计算页码，翻页精准。
- **关键词搜索定位**：支持循环跳转、正文内联高亮、显示第 X/N 个匹配。
- **纯净阅读模式**：一键隐藏 UI，自定义字号、字体、宽度与背景色。
- **护眼主题**：明亮暖纸感 / 暗色非纯黑柔对比，明暗一键切换。
- **自动翻页**：可设定 15–90 秒/页，空格启停。

## ⌨ 快捷键

| 按键 | 功能 |
|------|------|
| `PageUp` | 上一页 |
| `PageDown` | 下一页 |
| `Home` | 跳到开头 |
| `End` | 跳到结尾 |
| `空格` | 启停自动翻页 |
| `R` | 进入 / 退出纯净阅读模式 |
| `Esc` | 退出纯净阅读模式 |
| `Ctrl` + `↑` | 上一个文件 |
| `Ctrl` + `↓` | 下一个文件 |
| `Ctrl` + `←` | 上一处匹配 |
| `Ctrl` + `→` | 下一处匹配 |

## 🚀 基本操作

1. 点击顶栏「**打开文件**」或「**打开文件夹**」载入 TXT 文件
2. 在左侧「文件列表」切换文件，在「搜索定位」输入关键词并按回车或搜索按钮跳转
3. 在顶栏可调整编码、换行、字号、主题，点击「📖 纯净阅读」进入沉浸模式
4. 在纯净阅读模式下，可调整字号、字体、页面宽度与背景色，按 R 或 Esc 退出
5. 阅读进度会**自动保存**；需要时点击翻页栏「**↺ 恢复进度**」回到上次阅读位置

> **提示**：编码/字号下拉框聚焦时，PageUp / PageDown 不会触发翻页，避免误操作。

## 📦 本地使用

1. 下载仓库中的 [`index.html`](blob/main/index.html)
2. 双击用任意现代浏览器打开即可
3. 无需安装、无需后端、文件不上传，纯本地运行

## 🔧 技术说明

- 单个 HTML 文件，内联 CSS + JS，零外部依赖
- 使用浏览器 `FileReader API` 读取本地文件，不上传服务器
- 使用浏览器 `localStorage` 保存阅读进度与设置
- 大文件排版优化：采样估算真实显示行，提速约 100× 以上
- 兼容现代浏览器（Chrome / Edge / Firefox / Safari）
